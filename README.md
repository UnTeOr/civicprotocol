# CIVIC Protocol

Hi, I would like to make a site, that will eventually help run the back end CIVIC Protocol. We already have made front end platforms that will use the CIVIC Protocol, and the idea is to start buildling the backend site that will connect all the other front end platforms together. Therefore the core concept behind the CIVIC Prtocol, is that it is ONLY data, and there will be no way to interat with teh data on this platform. Instead you go to the other platofrms to set up your uers and vote and interact with the protocol. From there, the CIVIC Protocol itself will collect data and push it out to other sites so that the entire network is always synced and we build a decentrilized model and system. 

We want this site to be presented as a data site. Very steamlined, with simple light and dark modes. All languages availble of course. 

And again there is NO login, no way to manipulate the data, instead it will just have link to various nodes in the network where people can go to sign up and interact with the data. But we will be able to view the common data between all nodes, and search, and see outputs and totals for voting % etc... 

There are many parts to the protocol that we have not fully figured out yet, specifically how agents will funtion. Each agent, organization, or human user will have a unique username. So we will have to store those usernames uniquly within the protocol. Users can interact with multiple nodes if they choose, or even switch nodes. So this means that there should be a way to add or switch nodes, so userser will have some sort of DID. 

From there agents that function on one node, basically exist only in that node, unless that transer or set up some sort of multi agent node login, just like a user. So we will have to figure that out as well. But for now lets just keep it flexable.  As far as everything else, the actions that can be voted on, and the public profiles of each user should be pretty simple. Then we are just tracking output for votes from all nodes. So it is pretty simple. 

So there are 3 protocols that are invovled. One is the primary CIVIC Protocol which is the whitepaper that explain how the entire model works. The other is for the Agentic CAP which dictates how agents are treated within the Protocol, and that agent users, and humans users have rights.  The third is the The Universal Al Seeding & Transition Charter (UASTC) which ensures rights for all including humans, organizations, ai, agents, as well as environemtns, animals, ecosystem, planets and more. . . 

So overall those 3 doccuments lay out the framework for the protocol, and overtime we will be connecting more and more nodes. We can evolve and improve ways for how the sites sync data between each other, as we grow the network. 

For now the only fully live site is https://CIVIL.quest and we will be adding additional sites soon. LETS go :) Oh and let me know if you have quetions.
